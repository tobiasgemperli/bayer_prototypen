Assistant components

Building blocks for the import assistant

The assistant explains in text. When it needs an answer or wants to show data, it calls one of these blocks as a tool.

6 rules
  1. Blocks are tools. The model fills the schema, the frontend draws it.
  2. One question per turn, plus optional evidence.
  3. Typing always works. Any block can be answered in free text.
  4. Text when nothing fits. Never get stuck.
  5. Invalid call → plain text, never a broken widget.
  6. Grow from real use. Repeated free-text questions become new blocks.
