# docs/ — context for design work

In-depth context so a **challenge/brief** can become a **state-of-the-art interaction-design proposal** without re-explaining the product each time. (See the root `README.md` for the prototype's stack/structure and `CONVENTIONS.md` for build rules.)

## Read in this order
1. **[product.md](./product.md)** — what ResiYou is, the problem, users, the three pillars (Predict / Optimize / Comply), the credits model, and a domain **glossary**. The "why".
2. **[flows.md](./flows.md)** — the prototype's IA, screens and current user flows, how each maps to the real product, and the **open design opportunities**.
3. **[design-language.md](./design-language.md)** — reusable components/interaction patterns + the **UX principles** to hold in every proposal.
4. **[working-with-claude.md](./working-with-claude.md)** — **how to brief me with a challenge** and **how I respond** (restate → analyze → options → recommend → build as a variant → verify). Includes a paste-able brief template.
5. **[ux-process.md](./ux-process.md)** — the **AI-driven design process** I run for any challenge: Research → Requirements → Ideation → Variations → Evaluation → Handoff.
6. **[research.md](./research.md)** — sources behind the above: ResiYou commercial research + how expert teams use AI for design.

## Concept work (current round)
- **[concepts/index.html](./concepts/index.html)** — the **concept-overview deck**: every project & variant with a flow diagram + what's-new (open in a browser; start the prototype for live links).
- **[concepts/SPEC.md](./concepts/SPEC.md)** — the concept spec (Spray plans, Draft state, Lab master–detail).
- **concepts/\*-discovery.md** — per-project discovery & requirements (Stage 1–2 of the process).

## TL;DR for briefing
Hand me a challenge (even one line). I'll frame it, analyze the existing flow from these docs, give **2–3 interaction-design options with trade-offs**, recommend one, and build it as a **comparable variant** (baseline untouched) — verified via build + headless screenshots.
